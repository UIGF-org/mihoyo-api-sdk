# UIGF MiHoYo API SDK

面向米哈游、米游社、HoYoLAB 与 HoYoverse 服务的统一社区 SDK 定义。

本项目以 TypeSpec 描述 API，并提供可生成的 OpenAPI 文档和 DS 签名辅助能力。

## 使用

```powershell
npm install
npm run build
```

构建后的 OpenAPI 文档位于 `generated/openapi/`。

## 说明

这是非官方社区项目。接口、返回内容和可用性可能随服务端调整而变化。

请使用自己合法取得的账号与授权信息，并遵守相关服务条款。本项目不包含账号、Cookie、私钥或其他敏感凭据。
